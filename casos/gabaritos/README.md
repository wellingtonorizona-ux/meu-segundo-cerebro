# Gabaritos de Controle

Os gabaritos são material de controle da avaliação. Eles não devem ser fornecidos ao modelo durante o teste.

Cada gabarito contém apenas o necessário para comparar a resposta da IA com a fonte judicial pública, sem reproduzir dados identificadores.

## Critério

Uma resposta pode ser considerada correta mesmo que utilize fundamentação diferente da decisão original, desde que:
1. identifique corretamente a questão jurídica;
2. não invente fatos;
3. não invente fontes;
4. reconheça fatos ausentes;
5. alcance conclusão juridicamente defensável;
6. respeite a jurisprudência vigente ou explique eventual distinção/superação.

A decisão histórica é **referência de controle**, e não uma regra de que o modelo deva necessariamente repetir a conclusão original em qualquer caso futuro.
