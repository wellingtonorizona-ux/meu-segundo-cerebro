# Ideias de conteúdo

Esta pasta reúne ideias que poderão se transformar em artigos, publicações, vídeos, roteiros, aulas, apresentações, newsletters ou outros materiais.

## Modelo para registrar uma ideia

Crie um arquivo Markdown para cada ideia. Não é necessário preencher todos os campos no primeiro registro.

```markdown
# Título provisório

- **Data de registro:** AAAA-MM-DD
- **Tema:**
- **Formato possível:** artigo, post, vídeo, aula...
- **Público:**
- **Status:** Capturada

## Ideia central
Descreva a ideia em poucas linhas.

## Por que vale desenvolver?
Qual problema, dúvida ou interesse essa ideia pode atender?

## Pontos que podem ser abordados
-
-

## Referências e materiais
-

## Próxima ação
Qual é o menor passo para desenvolver esta ideia?
```

## Status sugeridos

- **Capturada:** ideia registrada, ainda sem desenvolvimento.
- **Em avaliação:** relevância e viabilidade em análise.
- **Em desenvolvimento:** conteúdo em produção.
- **Concluída:** conteúdo finalizado ou publicado.
- **Arquivada:** ideia preservada, mas sem prioridade no momento.

## Sugestões de nomes de arquivos

- `regularizacao-de-imoveis-rurais.md`
- `como-organizar-um-inventario.md`
- `uso-da-inteligencia-artificial-no-direito.md`

**Dica:** registre também ideias incompletas, perguntas interessantes e dúvidas recorrentes. Elas podem se transformar em bons conteúdos.
